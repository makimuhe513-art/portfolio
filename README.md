# Muhammed Kedir — Portfolio

A responsive, dark portfolio starter with a red accent, animated lightning background, hover interactions, and a semicircular portrait placeholder.

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Personalize before publishing
1. Your supplied portrait is included at `assets/muhammed-kedir.jpg` and is displayed in the hero section.
2. C++ is listed as supplied.
3. King's Academy is listed as your school. Add exact study dates or a formal qualification only if accurate.
4. Social profile links are omitted for now, as requested.
5. Replace the future-project placeholders when you complete those projects.
6. Review the About section and adjust it to your own voice.

The education section intentionally does not invent a university, degree award, dates, certificates, or work history. Skills are presented as learning areas rather than claimed proficiency ratings.

## Deploy with GitHub Pages
1. Create a GitHub repository, for example `muhammed-kedir-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets/` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site; the published URL will appear in the Pages settings.

## Notes
- The lightning effect is decorative and respects `prefers-reduced-motion`.
- The contact link opens the visitor's email app using the email address supplied.
- Google Fonts are loaded from the web; system fallbacks remain available offline.
